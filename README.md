# React App

A minimal Vite + React + React Router starter, with Sass (including a
light/dark theme system) and Bootstrap wired up.

## Getting started

```bash
npm install
npm run dev
```

Then open the URL Vite prints (usually http://localhost:5173).


## Build

```bash
npm run build
npm run preview
```
